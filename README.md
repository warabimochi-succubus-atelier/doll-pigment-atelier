# Doll Pigment Atelier

成功した色を蓄積し、再現を支援するドールメイク用アトリエツールです。
仕様書（[SPECIFICATION.md](SPECIFICATION.md)）の「初期バージョン必須機能」を実装しています。使い方は [USER_MANUAL.md](USER_MANUAL.md) を参照してください。ビルド不要の静的 PWA（HTML / CSS / JavaScript）です。

現在の版は `js/version.js` の `APP_VERSION` です。0.x の間は、標準DB の絵具の K・S がまだ仮の値です（実測して同梱したら 1.0.0 にします）。

## 起動

```bash
python -m http.server 8765
```

ブラウザで http://localhost:8765/ を開きます（`index.html` を直接開いても動きます。Service Worker だけは http で配信したときに有効になります）。

## 公開

GitHub Pages で公開します（仕様書 6.1）。

- 公開 URL：https://warabimochi-succubus-atelier.github.io/doll-pigment-atelier/
- 設定：リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にする
- ビルドは不要です。main に push すると公開されます。
- 公開する変更では `js/version.js` の `APP_VERSION` を上げてください（例：`0.9.0` → `0.9.1`）。Service Worker のキャッシュ名はこの版から作るので、利用者の端末に新しい版が入り、画面に「新しい版があります」と表示されます。「更新する」を押すと切り替わり、古いキャッシュは消えます。

## 現在の制限と実装メモ

- 絵具の K・S は、まだ実測していません。カラーチャートの色見本から取った仮の色と仮の着色力から、RGB 3チャンネルで近似した値です（`js/paints-data.js`、`js/km.js`）。3.5 の見本撮影による推定は、開発用のツール（下記）で行い、結果を `js/paints-ks.js` に入れると、その絵具は実測値で計算します。
- メディウムは予測色の計算には含めていません。
- 保存先はブラウザの IndexedDB（データベース `dpa.atelier`）です。以前の版の localStorage（`dpa.userdb.v3`）のデータは、初回の起動で移します。画像は長辺 1600px の本画像と長辺 320px のサムネイルを Blob で保存し、カラーエントリから id で参照します。以前の版でエントリの中に持っていたサムネイルは、起動時に画像として取り出します（本画像は残っていないため、サムネイルを本画像として使います）。
- サンプルのカラーの調色記録は、追加するときに代表色を逆引きして作っています。

## K・S 推定ツール（開発用）

標準DB の絵具の K・S を、白との混色見本の写真から求めるツールです（仕様書 3.5）。アプリの画面からはリンクしていません。

1. 起動したサーバーで http://localhost:8765/tools/ks-estimator.html を開く
2. 見本の写真を読み込み、「グレーカードを指定」でグレーカードを囲む
3. 絵具と割合（絵具 : 白）を選んで、各見本を囲む。白だけの見本も、ラインの白を選んで囲む
4. 「結果」で K・S と ΔE を確かめ、「paints-ks.js を書き出す」で作ったファイルを `js/paints-ks.js` と置き換える
5. 公開するときは、いつもどおり `js/version.js` の版を上げる

「テスト画像で試す」を押すと、仮の K・S を正解として作った見本の写真（照明の色かぶり・露出の違い・ノイズ入り）で、手順2〜4を自動で行います。見本の指定はブラウザに自動で保存され、「作業を書き出す」で JSON に残せます（写真は保存しません）。
