リキテックス

持っている絵具に「所持」のチェックを入れてください。逆引き調色は、所持している絵具だけで候補を出します（レギュラー・ソフト・ベーシックスを混ぜて使えます）。使い切った絵具は「切らした」を押すと、所持の登録を残したまま、買い直すまで候補の計算に使いません。白との混色見本（絵具のみ / 1:1 / 1:4 / 1:10）は予測の色です。

所持絵具白との混色見本

バックアップ

レシピ帳（画像を含む）と絵具箱の設定を、ZIP ファイル1つにまとめてエクスポート・インポートします。以前の版で書き出した JSON ファイルも読み込めます。

データ保存

データは端末内だけに保存し、サーバーには送信しません。参考画像と記録画像は個人の参考用で、アプリから公開・共有しません。

このアプリについて

  • 調色候補は、各絵具の色（カラーチャートの色見本の色）から Mixbox で混色を計算した目安です。絵具ごとの着色力の違いや、メディウム・塗り方・下地の色は計算に入りません。提案される割合は出発点として使い、実際の見本で確かめてください。
  • データと画像はこの端末のブラウザ（IndexedDB）に保存します。画像は長辺 1600px に縮めて保存します。
  • 作者・ライセンス・マニュアルへのリンクは、画面右上の ⓘ から開けます。

グレーカードを一緒に写しておくと、あとで色を補正できます。
